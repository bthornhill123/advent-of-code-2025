# Advent of Code 2025

My solutions for [Advent of Code 2025](https://adventofcode.com/2025), written in TypeScript.

## Structure

- `src/dayX/`: Contains the solution and input for each day.

## Running Solutions

To run a specific day's solution, you can use the npm script:

```bash
npm run start:day1
```

Or run it directly with `ts-node`:

```bash
npx ts-node src/day1/index.ts
```

## Running Tests

This project uses the native Node.js test runner. To run all tests:

```bash
npm test
```

## Prerequisites

- Node.js
- npm

Install dependencies:

```bash
npm install
```
