# Advent of Code 2025

My solutions for [Advent of Code 2025](https://adventofcode.com/2025), written in TypeScript.

## Structure

- `src/dayXX/`: Contains the solution and input for each day.

## Running Solutions

To run a specific day's solution, use `ts-node`:

```bash
npx ts-node src/day01/index.ts
```

## Prerequisites

- Node.js
- npm

Install dependencies:

```bash
npm install
```
